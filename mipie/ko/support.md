# 지원

**MiPie** — 머물러서 작업한 곳의 와이파이를 조용히 지도에 남기는 iPhone 앱입니다. 카페,
도서관, 청년센터 같은 곳이지요. 기록된 지점에는 반경 50m 원이 그려지고, 이는 "이 범위 안
어딘가에서 이 와이파이를 썼다"는 뜻입니다.

## 기록이 안 될 때

MiPie는 접속한 와이파이 중 **일부만** 일부러 기록합니다. 조용했다면 아래 중 하나입니다.

| 화면 | 이유 |
|---|---|
| 앱을 열어도 아무 일이 없음 | 이미 기록된 네트워크입니다. 네트워크당 한 번만 기록하고 그 뒤로는 조용합니다 |
| "개방형 와이파이는 기록하지 않아요" | 비밀번호나 로그인이 필요 없는 망입니다. 길거리나 대중교통에서 자동으로 붙는 것까지 쌓이면 지도가 의미를 잃습니다 |
| "이동 중에는 기록하지 않아요" | 이동 중이거나, 최근 몇 분 사이에 차를 탄 이력이 있습니다 — 신호등에 선 버스 안도 포함됩니다 |
| "개인 핫스팟은 기록하지 않아요" | 핫스팟은 장소가 아니라 사람을 따라다닙니다 |
| "위치를 정확히 잡는 중이에요" | 위치 오차가 100m를 넘습니다. 50m 원을 그리는 앱이라 그보다 부정확하면 원이 거짓말을 하게 됩니다. 지하·지하철에서 흔합니다 |
| "와이파이에 연결해 주세요" | 셀룰러만 켜져 있습니다 |
| "동작 및 피트니스 권한이 필요해요" | 활동 이력이 없으면 카페와 버스를 가를 수 없어 기록하지 않습니다. 버튼을 누르면 설정으로 갑니다 |

**권한이 둘 필요합니다.** 위치는 "앱을 사용하는 동안" + **정밀 위치 켜짐**이어야 합니다 —
iOS가 정밀 위치를 승인한 앱에만 와이파이 이름을 알려주기 때문에, 이것이 꺼져 있으면 기능
자체가 성립하지 않습니다. 동작 및 피트니스도 허용해야 하며, 거부하면 기록이 만들어지지
않습니다.

**앱이 켜져 있어야 합니다.** iOS는 백그라운드에서 와이파이 연결을 앱에 알려주지 않습니다.
그래서 접속한 상태로 MiPie를 열었을 때 기록이 만들어지고, 앱을 열지 않으면 기록되지
않습니다. 우회할 방법이 없습니다.

## 기록 지우기

핀을 누르고 **이 기록 지우기**를 누르면 됩니다. 지울 수 있다는 것이 의도된 탈출구입니다 —
어떤 조건도 완벽하지 않아서, 원하지 않는 기록은 언제든 없앨 수 있어야 합니다. 앱을
삭제하면 전부 사라집니다.
